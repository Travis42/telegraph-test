## Question 1 — Is the ~90% baseline real? (SPEC-BASELINE Phase 1)

Design: 50 passages × 24 stratified questions (12 fact, 4 numeric, 4 ordering, 4 inference) = 1,200 target; 676 answers survived the 0.6 lexical-dedupe threshold. Every miss judged (taxonomy: grader_wrong / partial / wrong / ambiguous); sampled hits estimate grader false-positives.

- **Raw (strict lexical) accuracy: 89.6%** (606/676; Wilson 95% 87.1–91.7)
- **Judge-corrected: 99.85%** (675/676; 99.2–99.97)
- **Grader false-negative rate: 98.6%** — of 70 raw misses, 69 were correct answers the strict grader refused, 1 partial, **0 genuinely wrong**. Sampled-hit false-positive estimate: 0%.
- Per type (raw → corrected): fact 95.7→100 · ordering 88.0→100 · numeric 85.1→100 · inference 66.3→99.0

**Verdict:** the ~90% figure is real grader output but NOT real comprehension. True model capability on this instrument ≈ 99.9%; the entire gap is exact-match strictness. Caveat: the dedupe threshold dropped ~36% of generated questions (expected — near-duplicates echo passage text), so the answerable set is the deduped subset.

## Question 2 — Is information recoverable from cablese model OUTPUT? (SPEC-CABLESE)

Design: per passage, one 24-Q set used across all conditions (within-experiment pairing).
- **Record axis:** model writes a complete record in plain English (R-PLAIN) or telegraphese (R-CABLESE: drop articles/fillers, abbreviate, ALL facts retained, numbers/proper nouns verbatim); a fresh-context model answers the questions given ONLY the record.
- **Answer axis:** model answers from the passage in plain English (A-PLAIN-DIRECT) or cablese (A-CABLESE-DIRECT); each cablese answer is then decoded by a separate call given ONLY that answer.
- Context isolation is structural: every call is a stateless single-prompt request; the answering/decoding requests never contain the original passage. Shared model prior (same weights both sides) is the acknowledged boundary.

Results (corrected accuracy; n=727 per condition):
- **Token savings: 54.7%** — cablese records cost ~half the plain records' tokens
- **Recovery: 99.7%** — A-FROM-CABLESE 99.31% vs A-FROM-PLAIN 99.59%
- **Decode: 98.6%** — DECODE 98.21% vs A-PLAIN-DIRECT 99.59%
- A-CABLESE-DIRECT corrected 99.31%; per type: fact 100 · numeric 100 · ordering 98.8 · inference 96.4
- McNemar (raw grading): A-FROM-CABLESE **beats** A-FROM-PLAIN (discordants 105 vs 59, p=0.0004 — compressed records suppress verbatim-echo answers that the strict grader penalizes); DECODE < A-PLAIN-DIRECT (19 vs 145, p<1e-4) — raw cost of decoding vanishes under judge correction (all conditions 98.2–99.6 corrected)
- Decode fidelity: mean lexical similarity 0.45 — lossy in wording, not in answerable content
- Recall controls (R-CABLESE / R-PLAIN scored directly): fully dropped by the 0.6 dedupe threshold (expected — recall answers echo passage text); no scoreable data, noted as an instrument gap, not a finding

**Verdict:** cablese model output is informationally recoverable at ~99% fidelity while halving output tokens — both "leave a cablese note, read it later" and "reply in cablese, decode later" hold up.

## Grading integrity correction — SPEC-VALIDATION implemented & live (22:00)

**The violation (Theory, 2026-10-03 14:19):** the OR baseline pipeline had the
model author quiz items, answer them, AND judge the grader's misses — the
"corrected 97.8%" was self-graded. Only two fixes valid (14:28): passage-anchored
grading in code; authoring-time item validation in code. No LLM judges of any
family; no human adjudication feeding metrics.

**Implemented (OpenCode 25f6aa5..60a4024, 186 tests green, deployed lab 60a4024):**
- Grader v2 (`ab/grade.py`): pure functions; answer-vs-expected containment +
  mandatory anchor check (expected extractable from source passage, both at
  0.8 threshold, fixed normalization incl. digit/ordinal canonicalization).
- Validation gates: bank items at load; generated items BEFORE being asked;
  unanchored → rejected + logged; quotas from anchored pool only.
- Judge demoted to `diagnostics/` namespace; corrected headline deleted;
  `overall_raw` (v2) is the only headline.
- Retro-regrade tool (`python3 -m ab.regrade --run-dir <dir>`): re-grades a
  finished run from its ledger, zero API calls, original summary hash-protected.

**Code-anchored corpus (grader v2):**
- `or-c3-1255` (deepseek-v4.1-flash, OR): **91.2%** (542/594, Wilson
  [0.887, 0.933]) — replaces lexical 90.2% and self-graded "97.8%".
  Judge had claimed 45 grader-wrong overturns; code confirms **6**; **39
  unsupported** → same-model judging inflated the headline by ~6.6 pts.
  Registers: fact 95.5 / formulaic 93.7 / prose 87.1.
- `baseline_bl5` (zai GLM-max lane): **90.4%** (676; fact 90.9 / formulaic
  93.8 / prose 87.9) — this lane never ran the judge; v2 confirms as-is.
- `baseline_bl4` (46-answer run): 95.7%, unchanged.
- Cross-family read: deepseek-flash +0.8 pt overall, driven by fact register
  (+4.6 pt); **prose is the shared weak register (~87-88%) on both models**.
- bl1-bl3: superseded partials, no raw records to regrade. cablese cbl1/cbl2:
  no quiz-answer records (different measure, nothing to correct).

**Standing invariant:** no correctness value in any tcb output derives from
any model response except the answer under test. Future runs carry the gates
from the first slot.

## Prose probe verdict — presentation is NOT causal (23:55, run prose1)

Register-swap experiment (SPEC-PROSE): 24 prose passages listified by
LLM (anchor-gated in BOTH versions, 0 rejections, 0 drops), same
questions asked against both versions, both families, grader v2,
1188 answers.

| family | prose | listified |
|---|---|---|
| deepseek-flash | 88.2% | 87.2% |
| zai-max | 89.2% | 87.9% |

**Registered prediction REFUTED:** listification did not recover
accuracy for either family (Δ −1.0 / −1.3 pt, Wilson CIs overlap
completely). De-narrativizing the passage — facts fronted, position
controlled, structure regular — changes nothing.

**Conclusion:** the prose deficit is **item-register-side, not
passage-presentation-side**. It is a stable property of prose-style
items (longer verbatim answer spans), not of how the passage is
formatted. Consequences:
- No formatting intervention (listify/chunk/reorder) can close the
  87-89% prose band — it is the verbatim-reproduction cost of
  multi-token prose answers, uniform across both families.
- On matched items, families score within ~1 pt in every condition —
  the family gaps seen in baselines largely wash out on prose items.
- zai's threshold-band misses persist in listified form → the
  near-miss verbatim slips are answer-shape effects, not narrative
  interference. deepseek's low-overlap failures likewise unchanged.
- For compression work: preserving gist is NOT enough for prose
  content — verbatim token fidelity of answer spans is the binding
  constraint, and it is format-independent.
