# Token Codebook — Findings: Cross-Model Cablese Legibility Matrix (xm4)
**Date:** 2026-10-04 · **Run:** crossmodel_xm4 (canary 14671 + array 14672, 24/24 slices) · **Grading:** grader v2 (deterministic, passage-anchored) throughout; zero LLM judges in the truth path
**Artifacts (authoritative):** `lab:/root/projects/token_codebook/results/crossmodel_xm4/summary.json` (+ per-slice ledgers)
All numbers below re-derived from summary.json.

## Question
Is cablese a shared register across model families, or a GLM idiolect? (The kill-test for every applied consequence: routers, agent memory, the benchmark itself.)

## Design
Direction A — foreign readers on GLM-written records: each reader answers the same anchored question set from GLM's plain record (control) vs GLM's cablese record (treatment); recovery_ratio = cablese/plain accuracy.
Direction B — GLM reads foreign-written records: each writer produces plain + cablese records of the same passages (identical frozen cablese prompt); GLM answers from each; savings_pct = token reduction of the writer's cablese vs plain record.
Source items: cbl2's 24-Q sets, v2-anchor-filtered at load (19 unanchored rejected; per-passage anchored pools 5–28, quota-capped at 24 → 694 scored pairs). Panels: readers gemma-4-31b / qwen3.8-27b / nemotron-3-super-120b / gemma-4-26b-a4b; writers gemma-4-31b / qwen3.8-27b / gpt-5-mini (premium cell). Zero panel drops (adaptive reasoning-disable + empty-content retry/drop all held; no adaptation events fired in the final run).

## Results (Direction A — GLM writes, foreign models read)
| Reader | plain acc | cablese acc | recovery ratio |
|---|---|---|---|
| gemma-4-31b | 0.709 | 0.776 | **1.095** (McNemar p=0.0002) |
| qwen3.8-27b | 0.724 | 0.794 | **1.097** (p<0.0001) |
| nemotron-120b | 0.760 | 0.763 | **1.004** (p=0.56, parity) |
| gemma-4-26b | 0.718 | 0.767 | **1.069** (p=0.004) |

Every foreign reader does as well or BETTER on cablese than on plain. (Mechanism, unconfirmed hypothesis: compressed records suppress verbatim-echo answers that anchored grading penalizes — the same effect seen in cbl2's raw McNemar. Ratio >1 should be read as "no accuracy tax," not "cablese improves comprehension.")

## Results (Direction B — foreign writers, GLM reads)
| Writer | recovery ratio | token savings |
|---|---|---|
| gemma-4-31b | **1.069** (p=0.007) | 47.9% |
| qwen3.8-27b | **1.105** (p=0.0002) | 47.5% |
| gpt-5-mini (premium) | **0.996** (p=1.0, exact parity) | 26.7% |

Non-GLM writers compress ~48% under the same frozen cablese instruction. The out-of-family premium model writes cablese GLM reads back at exact parity, still saving ~27% — the literal router configuration, demonstrated.

## Verdict
**Shared register, not idiolect.** Recovery clusters 1.00–1.10 across four families in both directions; every significant McNemar favors cablese, none favor plain. The cross-model portability assumption behind every applied consequence (agent memory in cablese, tier-arbitrage routers, the Telegraph Test as an ecosystem property) survives its first honest test.

## Honest caveats
- Instrument note: cbl2 items were authored pre-v2; anchor filtering shrank per-passage n (pools 5–28). Absolute accuracies (70–79%) are not comparable to bl5's passage-direct 90.4% — different items, different context (records vs passage). Ratios are the claim; absolutes are context.
- cbl2's in-family recovery ratio (0.997 provisional, self-graded) still awaits the v2 regrade of its condition pairs — queued tooling task.
- One register definition, one passage bank (literary/mixed), 7 models, decode axis not yet cross-family.
